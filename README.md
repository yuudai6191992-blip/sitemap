# 技術マップ（Technology Map）

復建調査設計株式会社の保有技術を、**まちと自然の風景マップ**の上から直感的に探せるインタラクティブな Web アプリケーションです。山・河川・都市・海へと続くビジュアルな風景の上に技術をアイコン（ピン）で配置し、クリックすると詳細が開きます。もちろん従来型の**一覧（カード）表示**にも切り替えられます。

HTML5 / CSS3 / JavaScript（ES6）のみで実装しており、外部ライブラリやビルドツールは使用していません（風景イラストは SVG、立体表示は CSS 3D Transform で実現）。技術データは JSON で管理し、画面は JSON を読み込むだけで自動生成されます。

---

## 特長

- **🗺️ 風景マップ表示（メイン）**：山・ダム・河川・インターチェンジ・高層ビル街・高架鉄道・公園・港と海までを一望できる俯瞰の縮図の上に、技術をアイコンで配置。ホバーで名称、クリックで詳細を表示
- **🧊 立体（3D）表示**：「立体」ボタンで地図が浮島のように傾き、**ドラッグでグルグル回転**できます（横ドラッグ＝回転、縦ドラッグ＝傾きの調整）。⟲ ⟳ ボタンでも回せます
- **移動・拡大縮小**：平面時はドラッグで移動、立体時は Shift＋ドラッグ（または右ドラッグ）で移動。マウスホイール／スマホの2本指ピンチ／＋ − ボタンで拡大縮小。「全体」ボタンで初期表示に復帰
- **キーボード操作**：矢印キー＝移動、`Shift`＋左右＝回転、`+` / `-`＝拡大縮小、`0`＝リセット
- **ゾーンで絞り込み**：上部のゾーンチップ（複数選択可）で、その分野の技術だけを強調表示
- **☰ 一覧表示**：技術名・カテゴリ・概要・タグをカードで一覧（ホバーエフェクト付き）。ワンタップで切替
- **全文検索**：技術名・概要・説明・キーワード・カテゴリを対象にリアルタイム検索（複数語 AND 検索対応）。マップ／一覧の両方に反映
- **カテゴリフィルタ**：AI / DX / GIS / IoT / 防災 など、複数カテゴリを同時選択して絞り込み
- **詳細モーダル**：概要・特徴・適用事例・強み・関連技術・キーワード・保有部署・担当者・URL などを表示
- **タグ検索**：カード／詳細内のキーワードをクリックすると、その語で検索
- **関連技術リンク**：関連技術をクリックすると、その技術の詳細へ移動
- **ソート**：名称順 / カテゴリ順 / 新着順（一覧表示）
- **状態表示**：検索件数・現在の検索条件（パンくず）・ローディング・No Data 表示
- **レスポンシブ対応**：PC / タブレット / スマートフォン（狭い画面では拡大・移動して閲覧、または一覧表示に切替）
- **アクセシビリティ配慮**：キーボード操作、フォーカストラップ、`aria` 属性、`prefers-reduced-motion` 対応

## 背景イラストについて

背景の風景は **SVG（ベクター）** のため、拡大しても輪郭が滲まず常にくっきり表示されます。ビル・窓・街路樹・走行車・車線など反復の多い要素は、手描きではなく **生成スクリプト** で描画しています。

イラストは立体表示に対応するため **2枚に分かれています**。

| ファイル | 役割 |
| --- | --- |
| `assets/images/sky.svg` | 空・雲・気球・遠景の山なみ。**回転しない背景**として固定表示 |
| `assets/images/cityscape.svg` | 地面（原図の y=330 以降）。**回転する板**として3D変形の対象になる |

空を分離しているのは、立体表示で地図を回したときに「空が地面に寝てしまう」のを防ぐためです。地面イラストに要素を足す際は、**山などの高い地物の頂点が y=330 より下**に収まるようにしてください（切り取られてしまいます）。

```bash
# 風景イラストを作り直す（プロジェクトのルートで実行）
python3 tools/generate_cityscape.py
```

`tools/generate_cityscape.py` を編集すれば、ビルの色・密度・道路の経路・公園や港の配置などをまとめて調整できます（`building()` `tree()` `car()` `road_band()` などの部品関数を組み合わせる構成）。空レイヤーへ描く場合は `add()` ではなく `add_sky()` を使います。

> 描画順（奥→手前）は「空 → 遠景 → 大地 → 山・ダム → 河川 → 海 → 市街地の舗装 → 道路・IC → 公園・郊外 → 街路樹 → ビル群 → 高架鉄道 → 橋・港 → 気球」です。要素を追加する際はこの順序を崩さないでください。

## 使い方（ローカルでの起動）

技術データを `fetch` で読み込むため、**簡易 HTTP サーバー経由**で開いてください。
`index.html` をファイル（`file://`）で直接開くと、ブラウザのセキュリティ制限で JSON を読み込めません。

プロジェクトのルートで、いずれかを実行します。

```bash
# Python 3 が入っている場合
python3 -m http.server 8000

# Node.js が入っている場合
npx serve .
```

その後、ブラウザで <http://localhost:8000/> にアクセスします。

## データの追加・編集

`data/technology.json` の `technologies` 配列に項目を追加するだけで、画面へ反映されます（HTML の編集は不要）。将来的に 100〜500 件規模の登録を想定しています。

### データ項目

| キー | 型 | 必須 | 説明 |
| --- | --- | :-: | --- |
| `id` | number | ○ | 一意なID（関連技術の参照に使用） |
| `name` | string | ○ | 技術名称 |
| `category` | string[] | ○ | 技術分野（複数指定可） |
| `zone` | string | ○ | 風景マップの配置ゾーン（`zones` の `key`。例：`city`） |
| `icon` | string | | ピンに表示する絵文字アイコン（例：`"🗺️"`） |
| `pos` | object | | 地面イラスト上の配置座標 `{ "x": 66, "y": 41 }`（`cityscape.svg` の幅・高さに対する％） |
| `summary` | string | ○ | 概要（カードに表示） |
| `description` | string | ○ | 説明（詳細に表示） |
| `features` | string[] | | 特徴（箇条書き） |
| `cases` | string[] | | 適用事例（箇条書き） |
| `strength` | string | | 強み |
| `keywords` | string[] | | キーワード（タグ検索対象） |
| `related` | number[] | | 関連技術のID |
| `department` | string | | 保有部署 |
| `owner` | string | | 担当者 |
| `url` | string | | 関連URL |
| `maturity` | string | | 技術成熟度（例：実用 / 実証） |
| `registered` | string | | 登録日（`YYYY-MM-DD`／新着順ソートに使用） |

### 記述例

```json
{
  "id": 1,
  "name": "AI画像解析",
  "category": ["AI", "画像解析"],
  "zone": "city",
  "icon": "🗺️",
  "pos": { "x": 66, "y": 41 },
  "summary": "画像認識技術",
  "description": "ディープラーニングによる…",
  "keywords": ["AI", "画像", "Deep Learning"],
  "related": [5, 8],
  "department": "技術開発部",
  "owner": "〇〇",
  "url": "https://example.co.jp"
}
```

> - カテゴリ一覧は JSON の `categories` 配列で指定します（省略時はデータから自動収集）。
> - 風景マップのゾーンは JSON の `zones` 配列（`key` / `label` / `icon` / `color`）で定義します。各技術の `zone` はこの `key` を参照します。
> - `pos` を省略した技術は中央付近に配置されます。100〜500件規模で登録する際は、ゾーンごとに `pos` の座標を調整して重なりを避けてください。

## 設計方針・拡張性

責務ごとにクラスを分離しているため、以下のような機能を後から追加しやすい構造になっています。

- CSV 読込 / Excel 出力
- お気に入り登録
- 管理画面
- 技術比較 / ネットワーク図表示
- 組織別 / 年度別 / 技術成熟度表示
- AI 検索

例えば「お気に入り」を追加する場合は `FavoriteManager` を新設し、`App.render()` のパイプラインに絞り込みを差し込むことで、既存コードへの影響を最小限に実装できます。
